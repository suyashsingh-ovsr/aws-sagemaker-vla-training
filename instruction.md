# Bimanual SO-101 — Step-by-step commands

Setup: 2 SO-101 leader arms, 2 SO-101 follower arms, 3 RealSense cameras (1 head, 2 wrists).

All scripts run from **repo root** unless noted.

---

## 0. Setup environment (one time)

```bash
cd ~/PycharmProjects/lerobot-so101-bimanual

# Create venv with Python 3.10 and install base + feetech + realsense deps
uv sync --python 3.10 --package lerobot --extra feetech --extra intelrealsense
```

Activate the venv for all subsequent commands in the same shell:

```bash
source .venv/bin/activate
```

---

## 1. Find RealSense serial numbers

**USB requirements:**
- Use USB 3.0 cables (labeled `SS` / SuperSpeed) and ports for 1280×720@30fps
- Each camera needs its own USB root port — avoid sharing hubs (check `Physical port` paths: two cameras on the same `3-4.*` branch will starve each other)
- On USB 2.0 cables: max usable profile is 640×480@15fps

Plug all 3 cameras, then:

```bash
lerobot-find-cameras realsense
```

Note the 3 serial numbers (`Id:` field) — you need them in step 2.

---

## 2. Edit camera.yaml

Open `scripts/camera.yaml` and replace the 3 placeholder serials:

```yaml
front:
  type: intelrealsense
  serial_number_or_name: SERIAL_HEAD        # <-- replace
  width: 1280
  height: 720
  fps: 30
wrist: # left
  type: intelrealsense
  serial_number_or_name: SERIAL_LEFT_WRIST  # <-- replace
  width: 1280
  height: 720
  fps: 30
wrist2: # right
  type: intelrealsense
  serial_number_or_name: SERIAL_RIGHT_WRIST # <-- replace
  width: 1280
  height: 720
  fps: 30
```

---

## 3. Register USB ports

Reiterate the command to register all ports

```bash
lerobot-find-port
```

Writes `scripts/port.yaml` with the 4 ports.

---

## 4. Calibrate arms

```bash
./scripts/robot/calibrate.sh
```

Follow interactive prompts for each arm (move to min/max positions).

---

## 5. Edit dataset config

Open `scripts/dataset_config.yaml`:

```yaml
num_eposides: 50
single_task: "describe your task here"
hf_user: your_hf_username
repo: your-dataset-name
push_to_hub: False
episode_time_s: 30
reset_time_s: 10
```

---

## 6. Test teleoperation

Verify arms + cameras work before recording:

```bash
./scripts/robot/teleop.sh
```

---

## 7. Record demonstrations

```bash
# Fresh start
./scripts/robot/record.sh

# Resume after interruption
./scripts/robot/record.sh --resume

# Delete existing data and restart
./scripts/robot/record.sh --reset
```

---

## 8. Replay episode (sanity check)

```bash
./scripts/robot/replay.sh --episode 0
```

---

## 9. Install GR00T dependencies

`flash-attn` can't be built by uv without NVCC available. Install it first with no build isolation, then sync:

```bash
# Step 1 — install flash-attn (needs NVCC and matching PyTorch CUDA version)
uv pip install flash-attn --no-build-isolation

# Step 2 — sync groot extras
uv sync --package lerobot --extra groot
```

---

## 10. Edit GR00T training config

Open `scripts/jobs/local/groot_training_config.yaml`:

```yaml
base_model_path: nvidia/GR00T-N1.5-3B
embodiment_tag: new_embodiment
output_dir: ./outputs/groot
steps: 10000
batch_size: 32
save_freq: 1000
lora_rank: 0           # set to 16 to reduce VRAM usage
tune_diffusion_model: true
tune_projector: true
tune_llm: false        # needs 80 GB+ VRAM if true
tune_visual: false     # needs 80 GB+ VRAM if true
```

---

## 11. Train GR00T

```bash
./scripts/jobs/local/train_groot.sh
```

Checkpoints saved to `./outputs/groot/checkpoints/`.

---

## 12. Deploy GR00T on robot

```bash
# Auto-uses last checkpoint
./scripts/robot/run_policy/run_groot.sh

# Use a specific checkpoint
./scripts/robot/run_policy/run_groot.sh --policy-path ./outputs/groot/checkpoints/005000/pretrained_model
```

## Config files

| File | Purpose |
|------|---------|
| `scripts/port.yaml` | USB ports for 4 arms (auto-generated by `register_port.sh`) |
| `scripts/camera.yaml` | RealSense serial numbers + resolution/fps |
| `scripts/dataset_config.yaml` | HF user, repo name, episode count, task description |
| `scripts/jobs/local/groot_training_config.yaml` | GR00T model path, fine-tuning flags, training steps |
